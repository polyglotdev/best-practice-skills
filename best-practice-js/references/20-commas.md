# 20. Commas

Handled by Prettier — see `references/prettier.md`. Our config sets
`trailingComma: "none"`, so the last element of a multiline array,
object, import list, or parameter list never has a trailing comma. Never
use leading commas. Do not manually add or remove trailing commas in
code you write — the formatter owns this.

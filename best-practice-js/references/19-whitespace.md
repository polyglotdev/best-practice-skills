# 19. Whitespace

Handled by Prettier — see `references/prettier.md`. Our config uses
2-space indentation, spaces (never tabs), and `bracketSpacing: true` so
object braces always get inner spaces (`{ a: 1 }`). Do not hand-format
whitespace, alignment, or blank-line runs — run the formatter and move on.
